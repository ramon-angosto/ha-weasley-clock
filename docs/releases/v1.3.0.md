# v1.3.0 — Automatic media images and clock snapshots

## Changes

- The card finds the configured clock face in Multimedia by default, so its YAML can be just `type: custom:weasley-clock-card`.
- Conventional face filenames are discovered automatically; ambiguous choices ask for an explicit image.
- Person subentries now accept a hand image and width/top/left layout values. Conventional hand filenames can be discovered by person name.
- Add a Snapshot button to the card, using its displayed images and layout.
- Add the `weasley_clock.snapshot` action to generate a PNG without an open dashboard.
- Return the generated file path, URL, media source ID, dimensions and skipped person entities for use in automations and screen integrations.
- Match current sensor angles, clockwise rotation, transparency and layer order.
- Write snapshots atomically into the clock media folder and report unavailable or missing-image hands.

## Updating

Requires **Home Assistant 2026.9 or newer**. Update through HACS, restart Home Assistant
and reload the dashboard. The card resource is `/weasley_clock/weasley-card.js?v=1.3.0`.

Set the optional clock-face image in Weasley Clock configuration, or upload a file
such as `reloj_weasley.png` to **Media > My media > weasley_clock**. Reconfigure each
person to set their hand image. Existing manual card YAML continues to work.

Use **Obtener captura / Snapshot** in the card, or call `weasley_clock.snapshot` in
an automation. The default file is `weasley_clock_snapshot.png` in the clock media
folder. Screen devices need access to the Home Assistant URL and PNG support.

The renderer uses local Multimedia or `/local/` images. External image URLs are not
supported for server-side snapshots. No browser is needed for automated captures.

## Validation

Real PNG tests verify rotation, transparency, layout, discovery and path boundaries.
An action regression test verifies that current angles are captured before rendering
and that unavailable hands are reported. Node tests cover automatic configuration,
card rendering, snapshot calls and error handling. A snapshot of the bundled example
graphics was generated and visually inspected.

Installation in a running Home Assistant instance remains to be verified.
