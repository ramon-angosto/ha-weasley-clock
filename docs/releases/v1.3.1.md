# v1.3.1 ? Fix Pillow dependency installation

The integration no longer requires exactly Pillow 12.3.0. It accepts Pillow
12.3.0 or newer, allowing Home Assistant to select its own constrained version
instead of failing dependency resolution when Core requires a newer release.

Clock rendering and snapshots are unchanged.

Update Weasley Clock in HACS and restart Home Assistant. There is no need to
remove the integration, reconfigure people, or install Pillow manually.
