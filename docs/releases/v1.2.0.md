# v1.2.0 — One clock, grouped people and browsable graphics

## Changes

- Group people as native person subentries inside one **Weasley Clock** integration entry.
- Rename **Weasley Clock Hub** to **Weasley Clock**.
- Migrate existing person entries while retaining their sensor IDs, devices and areas.
- Replace the numeric location count with 13 text sensors showing the configured names.
- Register the Lovelace card explicitly as a JavaScript module and refresh its resource URL.
- Make clock graphics browsable in Multimedia and support images in the local media folder.
- Copy existing graphics from `/config/www/weasley_clock` without overwriting uploaded files.
- Display template errors and missing or unavailable entity warnings in the card.
- Add a HACS installation guide, a clearer README overview and the MIT license.

## Updating

Requires **Home Assistant 2026.9 or newer**.

Update through HACS or replace the complete `/config/custom_components/weasley_clock`
folder, including `www`, `translations` and `media_source.py`. Restart Home Assistant
and reload browser/app pages. The integration should show version **1.2.0**.

Existing people migrate automatically; do not delete and recreate their entries.
Add new people inside the clock entry and reconfigure each person's subentry to edit
its template. Changing a position name requires updating templates that return it.

On Home Assistant OS, upload graphics in **Media > My media > weasley_clock**
(`/media/weasley_clock`). Existing `/local/weasley_clock/` image URLs remain valid.

If the card still reports that its custom element does not exist, verify the
JavaScript module resource `/weasley_clock/weasley-card.js?v=1.2.0` and reload the page.
